> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
> WinDivert способен вызвать предупреждение антивируса.  
> Это средство перехвата и фильтрации трафика, необходимое для работы zapret.
> Его могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и помещается в карантин. Такое обнаружение обычно называется `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительнее добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и укажите URL вручную. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS на уровне операционной системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * При использовании роутера Keenetic включите в его настройках пункт "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/OutpostStuff/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите нужный скрипт
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите в **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены значения стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - включение или отключение обхода для сервисов из `ipset-all.txt`.  
  Эта настройка полезна при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках показывается текущий режим:
    - `none` - ни один IP не проверяется
    - `loaded` - IP проверяется на наличие в списке
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена выбранного активного фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка доступных обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения
  - **`Run Tests`** - запуск тестов стратегий:
    - `Standard tests` - проверка сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe (обход).  
Если его нет, обратитесь к [#522](https://github.com/OutpostStuff/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В появившейся папке откройте `hosts` через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что hosts действительно сохранился.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/OutpostStuff/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Работоспособность стратегий со временем может измениться.**
> Стратегия, которая некоторое время работала, может перестать помогать после того, как её обнаружат.
> В репозитории собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP

- Поочерёдно проверьте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/OutpostStuff/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите компьютер
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите прежнюю папку zapret
- Загрузите новую версию [со страницы релизов](https://github.com/OutpostStuff/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа доступен флажок разблокировки, включите его, нажмите "Применить", затем "ОК"
- Распакуйте архив в новую папку в корне диска, избегая пробелов, специальных символов и кириллицы
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если выбранный вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию
- После обнаружения рабочего варианта включите его автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- Проверьте в service.bat, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` - в **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше сервис открывался.
- Дополнительные сведения: [#251](https://github.com/OutpostStuff/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте Discord в приложении и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте её.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/OutpostStuff/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/OutpostStuff/tg-ws-proxy)
- Либо подключитесь к бесплатному MTProto-прокси из интернета

### Не запускаются игры или нет сетевого подключения

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Обычно помогает следующий порядок действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если этого недостаточно, дополнительно включите `ipset any`

Учитывайте, что `ipset any` способен нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/OutpostStuff/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/OutpostStuff/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
